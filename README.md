# DL Sentinel

Developer-focused security scanning platform by DhivaLabs.

DL Sentinel scans repositories for exposed secrets, vulnerable dependencies, insecure code
patterns, container/infrastructure misconfiguration, API security issues, and smart-contract
risks, then produces structured findings and reports (terminal, JSON, Markdown, SARIF).

> This repository is under active initial development. See `docs/` for architecture and
> contribution guidelines.
